# Yamata

[Yamata](https://orochi-project.github.io/yamata) is the official beatmap editor for [Orochi](https://github.com/orochi-project/orochi), a Cytus-inspired rhythm game for the Game Boy Color.

_The name Yamata (meaning "eight branches") comes from the Japanese mythological eight-headed serpent [Yamata no Orochi (八岐大蛇)](https://en.wikipedia.org/wiki/Yamata_no_Orochi)._

## Local Setup

To run Yamata locally, the only thing you really need to install is [Node.js](https://nodejs.org/en). Once you have Node.js installed, follow the steps:

1. Clone the repository:

```bash
git clone https://github.com/orochi-project/yamata
```

2. Install all dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

If you want to build Yamata, you should use:

```bash
npm run build
```

## Contributing

### Reporting Issues

To report an issue or bug, visit Yamata's [issue tracker](https://github.com/orochi-project/yamata/issues) on GitHub.

### Pull Requests

To push your features or fixes into this official repository:

1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/my-feature`) or a fix branch (`git checkout -b fix/my-fix`).
3. Commit your changes (`git commit -m "feat: add new feature"`). **Please follow the [Conventional Commits](https://www.conventionalcommits.org) guideline when doing so!**
4. Push the branch (`git push origin feature/my-feature`).
5. Open a pull request with `contrib` as the base branch. Make sure to create a detailed title and description of your change.

Please follow the [GitHub flow](https://guides.github.com/introduction/flow) when submitting a pull request.
